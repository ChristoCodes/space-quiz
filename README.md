# Órbita

Órbita es un quiz interactivo en español sobre exploración espacial. Incluye preguntas de opción múltiple, explicaciones de las respuestas, seguimiento del progreso y una modalidad de orden aleatorio. La aplicación es autocontenida en `index.html` y no requiere dependencias ni un paso de compilación.

## Ejecutar localmente

Abre `index.html` directamente en un navegador. No hace falta instalar herramientas ni iniciar un servidor.

## Publicación

El sitio se publica en GitHub Pages mediante el workflow **Deploy to GitHub Pages** cuando hay cambios en `main`. También se puede iniciar manualmente desde la pestaña **Actions** del repositorio.
